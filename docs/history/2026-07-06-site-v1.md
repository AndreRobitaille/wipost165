# Initial implementation lessons

Historical summary, distilled on 2026-09-07. Superseded as a specification;
all prior design and implementation choices may be reconsidered.

The first implementation provided reusable page structures, event integration,
editor guidance, static checks, and a deliberately narrow deployment boundary.
Its platform-specific files and commands were removed in the Rails pivot.

Code ownership and live content ownership were different. Publishing a template
did not update content already stored by editors. Navigation could link to pages
that had never been created. A future implementation benefits from explicit
content ownership and checking actual destinations.

The static validator proved file and snippet presence, not runtime behavior.
Adding command aliases called build, lint, and typecheck did not create three
independent checks. Verification descriptions need to say what was actually run.
A repository containing templates was not itself a running development server.
