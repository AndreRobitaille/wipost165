# Veteran and patriotic visual references

September 7, 2026. Research requested after the owner rejected superficial changes
to colored panels and text. Messaging remains accepted; visual direction is open.
These are source references for discussion, not another proposed Post homepage.
Case studies describe particular projects; they are not assertions about the current
live websites. Images were inspected directly. Exhibit interactions were described
by their designers, not independently tested in this review.

## National Veterans Memorial and Museum — Rare Volume

[Designer case study](https://rarevolume.com/work/veteransmuseum/)

The project includes a military timeline, a globe, veteran data visualization and
Letters Home. The pictured interfaces combine archival photographs, texture,
portraits and a navigable time scale. This is exhibit/media design, not a homepage.

Application idea: an optional Post scrapbook pairing real past and present photos,
objects and short stories. A visitor could open a photo to learn who is pictured
and what connects it to the Post today. Keep current events directly accessible.
Requires approved archival material and accurate captions; do not invent history.

Images: `nvmm-timeline_1.jpg`, `nvmm-letters_1.jpg`.
Originals: https://rarevolume.com/rv-content/uploads/2019/12/nvmm_timeline_1.jpg
and https://rarevolume.com/rv-content/uploads/2019/12/nvmm_letters_1.jpg.

## Team Red, White & Blue — Rule29

[Designer case study](https://www.rule29.com/case-studies/team-rwb)

Its system draws on military patches and American imagery. The case study shows a
family of distinct event graphics, apparel, photography, print, web and app work.

Application idea: give confirmed recurring Post events recognizable artwork with
consistent Legion identity. Let the event lead visually; keep title/date/details
as accessible HTML. Borrow the sense of belonging and repeatable event treatment,
not Team RWB's eagle or an invented replacement Legion mark.

## The Mission Continues — Go Do Good

[Designer case study](https://godogoodtogether.com/the-mission-continues/)

The case addresses the tension between veteran identity and community service.
Observed artwork layers documentary photos, cropped silhouettes, textured surfaces,
bold type and a coherent campaign system across multiple formats.

Application idea: the featured event or service story becomes an art-directed
composition of actual people and activity. The same visual can support an invitation
or poster. Keep the veteran fellowship message, avoiding a constant recruitment or
work-assignment tone. This is a campaign/brand reference, not a site layout to copy.

Image: `tmc-collage.webp`.
Original: https://godogoodtogether.com/wp-content/uploads/2026/03/tmc-veterans-transforming-under-resourced-comunities.webp

## Project Healing Waters — Elva

[Designer case study](https://www.helloelva.com/work/project-healing-waters/)

The 2023 project explicitly addressed broadening participation beyond an established
Vietnam-era audience. Observed mobile artwork uses outdoor photography, tactile
surfaces, large type and integrated image/text composition. The visual experience
centers a shared activity. Its content and mission are distinct from this Post.

Application idea: show what being there feels like through actual activity, location,
and companionship. This is a useful art-direction and audience-transition reference,
not an argument for a fishing theme or the source site's technology.

## Additional heritage reference

[TAVERN: Old Overholt 250](https://tavern.agency/old-overholt-250) uses historical
labels, documents and archival graphics as design material. This is packaging,
not veteran web design. The useful method is to find the Post's own visual material
rather than apply generic patriotic decoration. The spirits context is not a
recommended Post positioning. No assets from this project were copied into the repo.

## Directions to compare before more implementation

1. A living Post scrapbook: past and present together, photographs and objects that
   reveal short stories, present-day event information always within reach.
2. An event-and-club identity: distinct recurring-event artwork, real action photos,
   and a visual language that feels at home on a shirt, invitation and website.

Neither is selected. Avoid tactical cosplay, generic eagles/flags, manufactured
nostalgia, and another rearrangement of the same hero and text sections.
The approved Legion artwork and brand requirements continue to apply.
